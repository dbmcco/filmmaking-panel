# Boords vs Krock for Sister

Date: 2026-03-13
Status: recommendation memo
Context: filmmaker already using `Claude Cowork`

## Bottom Line

Start her on `Boords`, not `Krock`.

Reason:

- she is already acclimating to `Claude Cowork`
- the next tool should lower cognitive load, not add a production platform
- Boords is more storyboard-native and easier to understand as "the place where the boards live"
- Claude can handle the surrounding admin burden: shot-list drafts, scene breakdowns, location clustering, tax-credit research, and packet drafting

Revisit `Krock` only if the project starts needing heavier review workflow, editor-facing integrations, or team/project coordination inside the same system.

## What She Needs Help With

From the current task list, the main burdens are:

- turning script into shot list and storyboard
- organizing review without chaos
- identifying location consolidations
- comparing state incentives and costs
- drafting tax-credit paperwork

Only the first two need a storyboard platform.
The rest are better handled by `Claude Cowork + Docs/Sheets + local files`.

## Recommendation

### Pick now

- `Claude Cowork`
- `Boords`
- `Google Docs/Sheets/Drive`

### Do not pick now

- `ftrack`
- `Frame.io`
- `Krock` as the primary system

Those tools may be useful later, but they are more system than she needs for early preproduction.

## Why Boords Wins Right Now

Boords' official docs currently show a clean filmmaker-facing workflow:

- `AI script import`
- `shot list view`
- `script editor`
- frame editor with drawing, shapes, text, imported images, and camera overlays
- guest sharing with frame-specific comments
- exports to `PDF`, `DOCX`, `XLSX`, `ZIP images`, `MP4 animatic`, and `Google Slides`

That maps well to her immediate need:

- Claude drafts the scene and shot structure
- she reviews or edits in Cowork
- Boords becomes the visual workspace and review surface

The key point is that Boords stays narrow.
It does not ask her to also adopt a larger review-and-project system.

## Why Krock Is Not First

Krock is more of a `creative review + project workflow` product with storyboard capability.

Its current official pages show:

- a storyboard tool on the Free plan
- board-stage features for importing scripts, adding notes, and exporting as PDF or video
- integrations with `Adobe Creative Cloud`, `Final Cut Pro`, `Slack`, `Calendar Sync`, and `Webhooks`

That is attractive if you want a broader operating system.
It is less attractive if the near-term goal is simply helping one filmmaker storyboard faster with less overhead.

The product surface suggests more moving parts:

- review workflows
- notifications
- integrations
- project management posture

That can be good later.
It is probably not what she needs while she is still getting comfortable with Cowork.

## Practical Comparison

| Criterion | Boords | Krock |
| --- | --- | --- |
| Best immediate role | Storyboard workspace | Review/project workspace with storyboard features |
| Fit for one filmmaker + AI helper | Strong | Medium |
| Review/comments | Good | Good |
| Script-to-board flow | Strong | Good |
| Exports useful to Claude workflow | Strong | Good |
| Broader integrations | Weaker | Stronger |
| Likely learning curve for her | Lower | Higher |
| Best long-term if team workflow grows | Medium | Stronger |

## What I Would Actually Tell Her To Do

1. Keep using `Claude Cowork` for the planning and paperwork side.
2. Use `Boords` as the single storyboard tool.
3. Let Claude produce:
   - scene breakdowns
   - draft shot lists
   - storyboard prompt text
   - location matrices
   - incentive comparison sheets
4. Let Boords handle:
   - frame organization
   - visual iteration
   - comments
   - external sharing
   - animatic exports

This keeps each tool in its lane.

## Fallback Trigger

Switch the recommendation from `Boords` to `Krock` if she says one of these:

- "I need tighter review flow with more people."
- "I need editor integrations."
- "I want the storyboard tool and review/project coordination in one platform."
- "We are getting buried in approvals and delivery tracking."

If those become true, Krock becomes much more compelling.

## Notes on Pricing and Friction

### Boords

Boords' current pricing page shows:

- `Standard` at `$0/month` with `1 user included`
- additional users at `$15/mo each`
- a `Workflow` tier also showing `1 user included` and extra users at `$15/mo each`

The page positions Boords around:

- frame-level sign-off
- client approval
- animatic export

That is straightforward messaging for a filmmaker.

### Krock

Krock's current pricing and packaging are more complex in the raw page data.
What is clear from the official page is:

- there is a `Free` plan with storyboard access
- `Pro` is paid
- there is a higher-end `Unlimited/Enterprise` option
- Krock emphasizes broader collaboration and workspace management

That reinforces the overall recommendation:

- Boords is easier to start
- Krock is easier to grow into if operations get heavier

## Recommended Operating Stack

### Now

- `Claude Cowork` for all text-heavy and planning-heavy work
- `Boords` for storyboards and animatics
- `Google Sheets` for budget/incentive comparison
- `Google Docs` for rebate and location packets

### Later, only if needed

- `Krock` if approvals and coordination outgrow Boords
- `Frame.io` if media review becomes the real bottleneck
- `ftrack` only if the production becomes a true multi-stage pipeline
